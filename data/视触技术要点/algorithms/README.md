# 视触传感器算法知识库

## 概述

本目录系统整理视触传感器（Vision-Based Tactile Sensor, VBTS）的算法知识，基于《技术实现路径系统分析报告》的核心发现，提供完整的算法分类、性能对比、实现指南和技术路线图。

## 核心发现（2026年2月28日更新）

### 1. 算法实现路径四大分类

基于技术文档和算法实现，VBTS算法可分为四大实现路径：

| 路径类别 | 核心原理 | 关键技术 | 代表项目 | 适用场景 |
|----------|----------|----------|----------|----------|
| **传统计算机视觉方法** | 基于经典图像处理、特征匹配、光流算法 | Hough圆变换、LK光流、数字图像相关（DIC） | 早期GelSight、DigiTac | 工业检测、稳定环境 |
| **深度学习端到端方法** | 使用深度神经网络直接从图像预测触觉信息 | CNN、Transformer、生成对抗网络（GAN） | Vision-to-Force网络、Tactile Transformer | 复杂场景、高精度要求 |
| **物理模型驱动方法** | 基于弹性力学、接触力学建立物理模型 | Hertz接触理论、Boussinesq解、有限元分析（FEA） | UVTac算法、基于物理的力估计 | 科研、需要物理可解释性 |
| **混合方法** | 结合物理模型和数据驱动方法 | 物理信息神经网络（PINN）、模型引导的深度学习 | 物理约束的触觉感知 | 平衡精度与可解释性 |

### 2. 算法性能关键数据

基于64个测试案例的验证结果：

| 算法 | 平均相对误差 | 平均绝对误差 | 计算时间 | 成功率 | 优化方向 |
|------|--------------|--------------|----------|--------|----------|
| **Hertz接触理论** | 67.8% | 11.83 N | 0.19 ms | 100% | 参数校准、多点接触扩展 |
| **Boussinesq解** | 34.0% | 5.09 N | 0.004 s | 100% | 正则化优化、网格简化 |
| **有限元方法** | 932.2% | 97.91 N | 18.34 ms | 100% | 刚度矩阵改进、自适应正则化 |

*注：Boussinesq优化后性能基于最优参数（网格分辨率=20mm，正则化参数=1e-8）*

### 3. 算法核心三要素

1. **特征提取与匹配**：
   - 核心任务：从噪声图像中提取稳定特征并建立对应关系
   - 关键技术：多尺度特征、鲁棒匹配、异常值剔除
   - 性能影响：决定位移测量精度和稳定性

2. **位移场到力场的映射**：
   - 核心任务：建立形变到力的物理或统计关系
   - 关键技术：力学建模、反问题求解、正则化方法
   - 性能影响：决定力估计精度和可靠性

3. **多模态信息融合**：
   - 核心任务：结合视觉、力、时间等多源信息
   - 关键技术：传感器融合、时间序列分析、注意力机制
   - 性能影响：决定系统鲁棒性和场景适应性

## 快速参考

### 算法选择决策树

```
应用场景 → 需求分析 → 算法推荐
    ↓
1. 工业应用（稳定性优先）
   → 传统计算机视觉方法 + 参数优化
   
2. 消费电子（精度优先）  
   → 深度学习端到端方法 + 硬件加速
   
3. 科研探索（可解释性优先）
   → 物理模型驱动方法 + 混合优化
   
4. 新兴应用（平衡需求）
   → 混合方法 + 自适应选择
```
